ArtOfAfrica

[![Project Status: Active](https://img.shields.io/badge/status-active-brightgreen)]()

A VR gallery website helping African artists to showcase their art. Users can explore artworks in a 3D virtual gallery, interact with art pieces, and read stories behind each artwork.

---

About the Project

My Motivation:  
I realized that in Africa art is less valuable I wanted to create a platform to display African art in a fun and interactive way, combining creativity and technology, I want the artists voices to be heard.

Problem Solved:
Provides a digital space for African artists whether through painting or photography to share their work, and for users to experience art without visiting a physical gallery.

Key Features:  
* 3D virtual gallery built with Three.js  
* Interactive VR experience  
* Artwork display with stories  
* User authentication, CRUD for artworks, comments, and likes  
* Responsive design 

Live Demo: [Visit ArtOfAfrica](http://169.239.251.102:341/~fatma.abdourahmane/ArtOfAfrica/)
